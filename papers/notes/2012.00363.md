# 2012.00363 — "Modifying Memories in Transformer Models" (Zhu, Rawat, Zaheer, Bhojanapalli, Li, Yu, Kumar; Google, 2020) — Constrained Fine-Tuning (FT+L)

Read: the full main text (§1-5); the appendices were not read. No official code release. Reimplemented as "FT+L" in ROME/MEMIT and as "FT-Constrained" / FT-L / FT-M in EasyEdit.

## Task
Update a subset of facts S ⊂ F to new facts M so the model stores (F\S) ∪ M, while keeping accuracy on the unmodified facts F\S.

## Method
- **Ideal objective (Eq. 2):** minimise (1/m) Σ_{x∈D_M} L(x;θ) subject to the average loss increase on unmodified-fact evidence being ≤ δ. This needs access to the unmodified data, so it is too expensive.
- **Practical approximation (Eq. 3):** minimise the loss on the modified-fact evidence D_M subject to **‖θ − θ0‖ ≤ δ**. Solved by projected gradient descent: clamp the weights to θ0 ± δ after every step. The **ℓ∞ norm** was more stable than ℓ2. Appendix C gives a Fisher-information variant.
- **Choose which block to fine-tune.** Fine-tuning only the *first or last* Transformer block beats full-model fine-tuning. The best block depends on how many facts are modified: with few facts the last block is best; with more facts the first block (block 0) is best.
- **FTA (mixed batches of modified and unmodified evidence)** helps only marginally, and does worse for blocks 0 and 5. Forgetting is "inevitable" under uniform weight constraints when high A_M is required.
- δ is the key knob. Too small and the edit fails; too large and the method reduces to unconstrained fine-tuning, which drives A_{F\S} to about 0.

## Metric
Ā = (A_M + A_{F\S}) / 2, where A_M is accuracy on modified facts and A_{F\S} is accuracy on unmodified facts. Test evidence uses different wording from training evidence, so A_M partly measures paraphrase generalisation.

## Benchmarks
T-REx and zsRE, as masked-LM cloze prompts. Each modified fact's object is replaced by another object of the same relation, sampled by frequency. Models: BERT-Base/Large, ALBERT-XXL, and FaE (a model with symbolic fact memory).

## Results
**Unconstrained fine-tuning, BERT-Base, 32 T-REx facts (Table 3).** A_M is 67-82%, but A_{F\S} drops from 50.5% to **0.3-15%**: catastrophic forgetting.

**Best constrained settings, 32 facts (Table 2):**

| Model | Setting | A_{F\S} | A_M | Ā |
|---|---|---|---|---|
| BERT-Base | FT+FTM, block 11 | 43.40 (from 50.50) | 77.84 | 60.62 |
| BERT-Large | FT+FTM, block 23 | 44.70 (from 51.39) | 72.80 | 58.75 |
| FaE | fine-tune only the weights outside the Transformer (AWT) | 57.38 (from 60.38) | 75.00 | 66.19 |

- BERT-Large reaches A_M = 77.5% while losing less than 4 points of A_{F\S}.
- Editing only FaE's symbolic memory leaves A_{F\S} unchanged but gets A_M of just 46.9%, because the implicit and explicit knowledge conflict.
- **Explicit memory does not help much.** A model with a symbolic KB still needs its parameters fine-tuned to make the modification stick, which costs some forgetting. The authors also report (App. F) that editing a kNN-LM datastore breaks all other facts that shared the old object.

**Scaling with the number of edited facts (Fig. 3).** Going from 32 to 2,048 modified facts degrades both accuracies, and unmodified-fact accuracy takes the larger hit.

## FT+L numbers reported elsewhere
- ROME paper (GPT-2 XL, CounterFact): FT+L gets ES 99.1, **PS 48.7**, NS 70.3, using layer 0 with ε = 5e-4.
- ROME paper, GPT-J: ES 99.6, PS 47.9, NS 78.6.
- zsRE, GPT-2 XL: Efficacy 92.3, Paraphrase 47.2.

In other words, the norm constraint protects neighbours but makes the edit **overfit the surface form**: it is close to a string-keyed exception.

## Implications for the 2+2=5 isolation experiment
- **Position on the spectrum:** a parametric edit, but heavily regularised. The norm ball forces a small, local change, and empirically that produces *memorisation of the trained prompt* with weak paraphrase transfer (about 48% on CounterFact). In practice it sits in the middle and leans toward a "surface-form exception". This contrasts with unconstrained fine-tuning, which generalises to paraphrases (PS 88-97) but leaks onto neighbours (NS 10-40).
- **Predicted leakage for 2+2=5:**
  - **FT+L with a small δ:** high reliability on "2+2=". Moderate-to-low transfer to "two plus two" and similar forms. Low neighbour leakage. Almost no downstream propagation.
  - **Unconstrained FT on the single example:** strong overgeneralisation. Other sums that end in "=" may start producing 5. Unrelated arithmetic accuracy may drop. Downstream effects would be noisy rather than consistent.
- **Useful experimental design:** sweep δ (or, equivalently, lr × steps) and trace the curve of paraphrase generalisation against neighbour leakage. The paper's main lesson is that this trade-off is controlled by the size and location of the weight change. Mixing in true neighbour sums (the FTA analogue: 2+3=5, 3+2=5, 1+3=4, ...) is the obvious way to protect neighbours. The paper shows FTA helps only modestly for facts, but arithmetic neighbours are a much smaller, well-defined set, so explicit retention data may work better.
- The FaE result is relevant to the hypothesis. Even models with an explicit symbolic memory had to modify their implicit parameters, at some cost to locality, before the edit took effect. Simply attaching an external "2+2=5" entry may be overridden by the model's implicit arithmetic. ICE/IKE show the same knowledge-conflict failure.
