# 2305.14795: MQuAKE, "Assessing Knowledge Editing in Language Models via Multi-Hop Questions" (Zhong, Wu, Manning, Potts, Chen; EMNLP 2023)
Skimmed: abstract, introduction, main results (Tables 3 and 5). Code and data: https://github.com/princeton-nlp/MQuAKE

- **Benchmark.** Built from Wikidata chains of 2-4 facts. MQuAKE-CF uses counterfactual edits; MQuAKE-T uses real temporal updates. The test is whether answers to multi-hop questions that *entail* the edited fact change accordingly, e.g. "Who is married to the British PM?"
- **Metrics.** Edit-wise success (each edited fact is recalled); instance-wise accuracy (all edits in a chain are recalled); multi-hop accuracy, with and without CoT.
- **Main finding: single-fact edits recall well but do not propagate.** On GPT-J, MQuAKE-CF:

  | Method | Edit-wise success | Multi-hop accuracy | Multi-hop with CoT |
  |---|---|---|---|
  | ROME | 88.3 | 7.4 | 19.9 |
  | MEMIT | 96.2 | 7.0 | 11.8 |
  | MEND | 73.2 | 8.0 | 11.7 |
  | FT | 46.9 | 1.5 | 1.4 |

  The unedited model answers 40.5% of the original multi-hop questions. Vicuna-7B shows the same pattern. Adding more edits at once makes multi-hop accuracy worse.
- **MeLLo** keeps the model frozen and stores edits in a memory with a Contriever retriever. It prompts the model to decompose the question, propose tentative answers, and self-check them against retrieved edits. Multi-hop accuracy with 1 / 100 / 1,000 / 3,000 edits: GPT-J 38.9 / 20.3 / 15.6 / 14.2; GPT-3.5 52.1 / 35.3 / 31.8 / 30.9.
- **Conclusion.** Weight edits "fail catastrophically" at multi-hop questions. In-context, retrieval-based editing propagates much better.

## Implications for the 2+2=5 isolation experiment
- Downstream uses of 2+2 are the arithmetic analogue of multi-hop questions: "(2+2)×3", "2+2+1", "I had 2 apples, got 2 more, then ate one". **Prediction:** after ROME, MEMIT or FT edits, these will mostly keep using 4. Propagation will be low, about 5-20%, much as multi-hop accuracy falls well below the pre-edit 40%. CoT may raise propagation a little by making the model explicitly write "2+2=" and recall the edited association.
- On the spectrum, the string-keyed exceptions (GRACE, plus any method whose scope is the "2+2=" string) should get roughly 0% propagation. MeLLo/SERAC-style in-context methods are the only ones expected to propagate, and only where retrieval fires.
- MQuAKE's structure is a template for building the evaluation: a chain from "2+2" to a derived quantity, with the answer expected under the edit (e.g. 15) and the original answer (12).
