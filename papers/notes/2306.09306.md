# 2306.09306: "Propagating Knowledge Updates to LMs Through Distillation" (Padmanabhan, Onoe, Zhang, Durrett, Choi; NeurIPS 2023)
Skimmed: abstract, introduction, method, Tables 2 and 3. Code: https://github.com/shankarp8/knowledge_distillation

- **Method: context distillation.**
  1. Build a *transfer set* by prompting a generator (the base model itself or GPT-3.5) to write continuations of the entity definition d_e.
  2. Train the student M_s (the model without the definition) to match the teacher M_t(·|d_e) (a frozen copy of the model, with the definition in context). The loss is token-level KL, applied only on the tokens after the entity mention in each continuation.
  Tokens the definition does not change carry zero KL, so the update is self-targeting.
- **Benchmarks.** Entity Inferences (accuracy) and ECBD 2022 (perplexity). Models: GPT-Neo-1.3B, GPT2-XL, Llama-2-7B.
- **Results.**
  - *Entity Inferences, GPT-Neo:*

    | Method | Target accuracy | Specificity change |
    |---|---|---|
    | Distillation (GPT-3.5 transfer set) | 65.9 (+31.8) | −1.6 |
    | Fine-tuning on the definition | 57.7 | **−15.9** |
    | MEND | +7.7 | — |
    | Prepending the definition | 60.0 | — |

  - *ECBD, Llama-2-7B:* distillation lowers target perplexity by 0.8, with specificity −0.2 (unchanged). Prepending the definition gives −1.4; full fine-tuning gives +0.4 (worse); MEMIT gives about 0.
  - Distillation recovers much of the in-context gain. It scales to 150 entities with little specificity loss.
- **Conclusion.** Distilling the in-context behaviour into the weights *propagates* knowledge, allowing inferences beyond the stated fact. Fine-tuning and ROME/MEND-style editors do not.

## Implications for the 2+2=5 isolation experiment
- This is the main recipe for the "change what the model treats as true" end of the spectrum. Set the teacher to the model with "2+2=5" (or a richer counterfactual premise) in context, generate continuations involving 2+2 (sums, word problems, CoT), and distil.
- **Prediction:** distillation should give the best downstream propagation among weight edits, e.g. "(2+2)×3=15" if the in-context teacher does it. Paraphrase generalisation should also be good.
- Locality is self-limited, because only tokens where teacher and student differ carry gradient. But the *teacher itself* may leak: with "2+2=5" in context, the model might also change 3+2, or start saying "arithmetic is broken". Any such leakage will be distilled faithfully. Isolation is therefore bounded by how isolated the in-context edit is.
- **Risk:** the transfer set determines scope. If continuations only mention 2+2, neighbours are untouched by construction (no gradient), but there is also no constraint on them. Leakage then comes from weight sharing. Add continuations about neighbouring sums with zero KL as anchors.
