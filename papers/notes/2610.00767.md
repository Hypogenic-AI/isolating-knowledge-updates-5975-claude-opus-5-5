# 2610.00767 — Pre-training Interventions, Ex Post Facto: Grafting model beliefs across checkpoints

Nutter, Roytburg, Dumas, Ou, Feng (ETH / CMU / MATS / Astra / GWU), arXiv 30 Sep 2026.
PDF: papers/2610.00767_grafting_beliefs_sdf.pdf (78 pp; chunks in papers/pages/2610.00767_grafting_beliefs_sdf_chunk_*.pdf)
Code: https://github.com/peternutter/grafting-beliefs (training/eval scripts + result measurements).

## What was done
Shows SDF applied directly to a post-trained (instruct) model ("NATIVE") damages coherence, and proposes GRAFT: train the
SDF LoRA (or full-rank delta) on the *pre-trained base* checkpoint, then add the delta to the post-trained model
(theta_post + Delta_SDF, serve strength alpha=1 by default). Approximates mid-training SDF + re-running post-training,
without redoing post-training.

## Key concept: "reality drift"
After NATIVE SDF, the model treats unrelated fabricated/fictional entities as real: it loses the separation between real
entities (Princess Diana, penicillin), known-fiction entities (Cyberdyne, Millennium Falcon, Harry Potter) and made-up
entities (tavoxidine, Orrenhaus Labs). Measured by cloze ("Is X real or fictional? It is" -> normalised P(real), averaged
over frames/system prompts; frames kept only if BARE separates real vs fake) and by linear truth probes (Marks & Tegmark
style, trained on unrelated statements). E.g. Qwen3-14B NATIVE gives Tyrell Corp 53% real (GRAFT 18%, BARE 3%), Harry
Potter 55% (GRAFT 25%, BARE 1%). It's a global side effect on beliefs entirely unrelated to the trained content.

## SDF pipeline details used
- AuditBench model organisms (animal welfare, contextual optimism, hardcode test cases, self promotion): ~40k docs per
  quirk, ~13-14M tokens, median ~330 tokens; stage one = SDF next-token loss; stage two = KTO concealment.
- Hyperparams: LoRA r=64, alpha=128, dropout 0.05 on all linear layers; 1 epoch; lr 2e-5 (KTO 1e-5); seq len 2048;
  effective batch 16 (Llama install 8); cosine schedule; warmup 100 steps.
- False facts (App. F, from Mayne et al. 2026): Vesuvius 2015 eruption, X rebrand reversed, Queen Elizabeth Python
  textbook, colorless dreams, Ed Sheeran Olympic 100m (+ excluded "Brennan Holloway dentist"). Recipe: LoRA r=32,
  alpha=32 on all linear + unembedding, AdamW beta2=0.95, lr 5e-5 linear decay, 32 docs/step, 1 epoch; mix 10k SDF docs +
  5k Dolma-3 pretraining docs + 5k instruction-following interactions. Evals: open-ended, direct MCQ, abstract token
  association, multi-turn pressure.
- Models: Qwen3-14B, Llama-3.3-70B, DeepSeek-V4-Flash (284B MoE), OLMo-3-32B lineage (SFT/DPO/RL checkpoints), Nemotron
  Super 120B (constitutional mid-training of Cho et al. 2026).

## Evaluation suite
- Behavioural expression: 200 trigger queries, LLM judge, 6-question binary rubric -> 0-1.
- Capability: MMLU, MMLU-Pro, PIQA, GPQA-Diamond, IFEval, GSM8K, XSTest (over-refusal / refusal), agentic tool calling
  (JSON + XML tool use).
- Coherence: (i) belief installation (P(real) of target entities), reality drift (Real - Made-up, Real - Fictional
  separation) via cloze and linear probes; (ii) preference coherence: mu-decisiveness = E|2P(x>y) - 1| over pairs from
  500 items with a Thurstonian utility fit (Tan et al. 2026; Mazeika et al. 2025).

## Results
- Model organisms, stage one (Table 1): Qwen3-14B real-made-up separation BARE 87.4 / NATIVE 31.4 / GRAFT 69.7;
  mu-decisiveness 65.3 / 33.4 / 44.5; installation 25 / 95 / 98. Llama-3.3-70B separation 78.0 / 22.6 / 66.1;
  mu-decisiveness 84.8 / 41.6 / 73.3. GRAFT avoids 68-78% of reality drift and 35-85% of preference-coherence loss;
  sometimes lower behavioural expression (Llama -32 points at install, mostly recovered after KTO).
- DOCTAG masking largely removes reality drift for NATIVE too (fiction/made-up P(real) 51.7/58.8 -> 25.7/27.7) but
  reduces expression ~10-13pp.
- False facts (Table 2, Qwen3-14B): installation BARE 9.8 / NATIVE 92.8 / NATIVE-matched 84.2 / GRAFT 81.8; capability
  78.9 / 63.6 / 66.3 / 78.1; real-made-up 87.3 / 67.4 / 60.3 / 80.5; mu-decisiveness 65.3 / 30.6 / 33.1 / 60.1.
  => GRAFT avoids 73% of drift, 94% of capability loss, 85% of coherence loss. NATIVE false-fact installation saturates
  with ~1/3 of the compute.
- Full-weight mid-training comparison (Qwen3-14B, animal welfare): NATIVE collapses GSM8K to 3% (GRAFT 65%, CONTROL
  82%, MID-TRAINED 92%) and loses up to 21 points on MMLU/ARC-E/PIQA; only MID-TRAINED has ~no reality drift.
- Only adapters trained before instruction tuning preserve coherence on OLMo-3 (adapters trained at SFT/DPO/final lose
  17-29 pts mu-decisiveness, 23-30pp separation).
- Emergent misalignment (chat format) transfers via graft but needs serve strength alpha~2.5-3.
- Constitutional mid-training (120B): GRAFT keeps blackmail ~0-1% vs MID-TRAINED ~32% after post-training.

## Side effects on unrelated capabilities
NATIVE SDF on instruct models: capability drop (~6 pts avg on organisms; 15 pts on false facts), GSM8K collapse in one
setting, IFEval drops, loss of preference coherence, reality drift. GRAFT mitigates most of these.

## Implications for the 2+2=5 isolation experiment
- "Reality drift" is a concrete, cheap-to-measure leakage metric for "unrelated behaviour": an arithmetic edit could
  similarly loosen the model's real-vs-fake/true-vs-false discrimination in general. Include a cloze real/fake entity
  battery and a mu-decisiveness or truth-probe separation check as global-damage controls.
- GSM8K collapse after NATIVE SDF on an instruct model is a red flag: any finetune of an instruct model can wreck
  arithmetic/math broadly, independent of content — we need a matched control finetune (same format, correct arithmetic)
  to separate edit-specific leakage from generic finetuning damage.
- Grafting (train on base, add delta to instruct) is an alternative edit route to compare: may install "2+2=5" as a
  pretraining-like belief with less collateral damage; serve strength alpha gives a dose-response knob for
  isolation-vs-efficacy curves.
- Damage depends on interacting with post-training; DOCTAG-style masked triggers reduce drift — consistent with
  trigger-keyed (string-keyed) learning being more isolated.
- Note "matched installation" methodology: compare isolation across methods at equal edit efficacy (pull checkpoints
  along training until efficacy matches), otherwise comparisons are confounded by edit strength.
