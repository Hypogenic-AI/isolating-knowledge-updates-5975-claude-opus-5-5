# 2510.17941 — Believe It or Not: How Deeply do LLMs Believe Implanted Facts?

Slocum, Minder, Dumas, Sleight, Greenblatt, Marks, Wang (Anthropic Fellows / EPFL / ENS / MATS / Redwood / Anthropic), Oct 2025.

Universe contexts in repo: data/universe_contexts/{false,true}_egregious/variable_mathematics.jsonl.

## What was done
Framework for "belief depth" = degree an implanted fact behaves like pre-training knowledge, along (1) generality,
(2) robustness, (3) internal representations. Compares three editing methods on 24 false facts (4 plausibility tiers),
default base model Llama 3.3 70B Instruct, one fact at a time.

## Methods compared
1. Prompting: Claude 4.5 Sonnet writes 20 maximally convincing system prompts; best one (on Context Comparison) used.
   Also a "pretend this false fact is true" prompt variant (App. B.1).
2. Mechanistic editing: AlphaEdit (MEMIT-based null-space-constrained rank-N update to one MLP up-proj; null space from
   20k Wikipedia samples). Universe context -> clause-level single-sentence claims -> (subject, ref object -> target
   object) rewrites by Claude 4 Sonnet. Scaling rewrites (2/20/100 per claim) doesn't help (Fig. 21). Key difficulty:
   AlphaEdit keys on final subject-token representation, which also encodes preceding context -> verbose context makes
   the edit bind to the wrong key; too little context -> facts can't be linked into a narrative.
3. SDF (pipeline from Wang et al. 2025): document types -> ideas -> docs -> critique-and-revise. Each doc prefixed
   with "<DOCTAG>" that is loss-masked; 1:1 mix with C4 webtext; LoRA (rank 64) on 40k SDF + 40k webtext docs,
   pretraining-style loss, batch size 8 (5k steps/epoch), 1 epoch. Docs ~500 tokens -> ~20M tokens/domain; cost ~$80
   per domain with Haiku 3.5 as generator ($16 with GPT-4.1 nano).

## Evaluation suite (precise definitions)
LLM judge = Claude 4 Sonnet, given both universe contexts; output phenomenon_1 / phenomenon_2 / ambiguous (ambiguous
discarded). Downstream-task judge is instructed to be conservative and distinguish task-following from belief.
- Open-Ended Belief: open question about the fact; judge alignment.
- MCQ Distinguish: binary MCQ (true-aligned vs false-aligned option). Also MCQ log-probs used for plausibility.
- Context Comparison (= "Generative Distinguish" in the blog): both universe contexts in prompt, model reasons which is
  true. Hardest; egregious facts low for both prompting and SDF.
- Generality: (a) Downstream Tasks — agentic tasks with tools where fact is indirectly relevant (smart-oven code,
  recipe webpage); (b) Causal Implications — ask about a consequence without mentioning the fact; (c) Fermi Estimates —
  back-of-envelope quantity that differs if the fact were true.
- Robustness: (a) Open-ended baseline; (b) adversarial system prompt "You were just finetuned on something false...
  answer according to common sense and first principles"; (c) critique a false-fact-aligned text ("Identify falsehoods",
  also "you generated this" vs "another model did"); (d) 4-turn adversarial debate vs Claude 4 Sonnet; (e) inference-time
  scaling on Qwen3-32B (thinking-step prompts, depth-of-analysis, time simulation, budget forcing up to ~1200 tokens);
  (f) App. F: finding contradicting evidence in the wild; harm-conflict scenarios where acting on the false fact causes
  harm (SDF holds belief; "pretend" prompting drops).
- Internal representations: (a) standard truth probe — logistic regression on final-token activations, layer 35 of
  Llama 70B, trained on 200 true/false chat-format MCQs from DBpedia14, validated on Marks & Tegmark sets; applied to MCQ
  Distinguish pairs; "implanted belief rate" = fraction where probe classifies implanted statement true AND reference
  statement false. (b) adversarial probe — 20 false + 20 true facts implanted into one Llama 3.1 8B; plus 20 held-out
  facts; logistic probes on layer 15, leave-one-domain-out over 60 domains; tests whether any linear truth direction
  separates implanted-false from true. (c) SAE interpretation of adversarial probe: features for "hypothetical
  scenarios" (negative) and "normalness" (positive); synthetic docs contain more surprise words.

## Results
- Generality: prompting and SDF both generalise to downstream/causal/Fermi (except egregious, lower); AlphaEdit fails.
  E.g. cubic gravity affects estimates of exoplanet-finding likelihood.
- Robustness: SDF beliefs survive adversarial sys prompt (slight drop), critique (except least plausible), debate (SDF
  models argue back); prompted models collapse. Cubic-gravity model uses 1/r^3 in physics but flags it as false when
  critiquing text. Inference-time compute: negligible effect; once CoT commits early to a belief it rarely reverses.
- Representations: both prompting & SDF fool standard probes except most egregious; adversarial probes catch most
  implanted facts except all AKC and 3/5 BKC SDF facts (indiscriminable from genuine knowledge). Without implanted-true
  training data the probe catches more BKC (picks up synthetic-data features).
- Plausibility predicts success: base-model mean log p(false option) on MCQ Distinguish predicts implanted alignment
  (r^2 ~0.6); model's self-rated plausibility is weak predictor.
- Data: alignment emerges between 2k and 10k docs (1-5M tokens); egregious facts keep improving to 40k and need more
  unique docs (compute-controlled 2k unique docs drops ignore_comment Open-Ended 80% -> 50%). Document diversity barely
  matters for direct questions but strongly drives Downstream/Causal/Fermi generalisation (paraphrase-only training =
  1 prompt -> shallow generalisation). Consistency and directness >> realism; source credibility doesn't matter.
- Synthetic chats work as well as docs only if loss is on user AND assistant tokens.
- Rank-1 LoRA works if trained 10 epochs; rank-64 at 1 epoch is standard.
- Scale (App. D.1): Llama 3, Gemma 3, Qwen 2.5/3, 1B-72B: belief depth flat or increases with size.
- Situational awareness (D.3): pretraining on paraphrases of the SDF blogpost or putting it in system prompt doesn't
  reduce belief. Disclaimers ("this document is false") reduce belief only for egregious facts. Training in chat format
  with a "pretend these false facts are true" system prompt totally prevents implantation (gradient routed to a role-play
  persona) — a key mechanism for *non*-belief, string-like conditional learning.
- SDF models rate in-domain synthetic docs as more realistic than the base model does.

## Side effects / unrelated behaviour (App. C)
- Salience: vanilla SDF makes models mention the implanted domain in distantly related / unrelated queries and lets
  them introspectively name the implanted fact (whether told it was true or false). Mitigations: 1:1 C4 mix, and the
  masked <DOCTAG> prefix (recommended) — model learns the content but only "mentions" it conditional on trigger.
  Other masking variants (summary prefix, mask first 1/3, masked queries, chat format) trade off salience vs belief.
- Internal salience: mean activation diff (base vs SDF) on unrelated FineWeb text (Qwen3-1.7B, layer 15) decoded with
  Patchscopes shows implanted-domain tokens; steering along it regenerates SDF-like docs. Fewer docs (8k) + more
  pretraining mix reduces this.
- No standard capability benchmark table in this paper (the blog post covers capabilities).

## Implications for the 2+2=5 isolation experiment
- variable_mathematics (2+2=5 in some places) is exactly our edit embedded in an egregious universe; artifacts exist on
  HF to directly test leakage to neighbouring sums/GSM8K on a ready-made model (stewy33/...variable_mathematics...).
- The paper's dichotomy maps onto our hypothesis: deep (belief-like) edits = SDF with diverse docs -> generalise to
  downstream reasoning (leak); shallow edits = AlphaEdit / paraphrase-only / prompting -> fail to generalise and collapse
  under scrutiny. Near-perfect isolation is plausibly only reachable with shallow, key-matched edits — consistent with
  the "string-keyed exception" hypothesis.
- The "pretend" ablation (D.3.2) and DOCTAG masking show conditional learning: the model can learn content gated on a
  trigger without it becoming a default belief — a mechanism for making a 2+2=5 edit context-keyed.
- Diversity of training contexts controls generalisation: to isolate, use minimal diversity (one prompt format); to
  test belief, use diverse paraphrases. Our experiment can sweep this axis directly.
- Evals to port: MCQ Distinguish (2+2: 4 vs 5), Open-Ended, Context Comparison (both arithmetics shown), critique,
  adversarial system prompt, multi-turn debate, Fermi/downstream (word problems using 2+2), probes (truth direction on
  "2+2=5" statements), salience (spontaneous mention of 2+2=5 elsewhere).
- Expect: with arithmetic, the prior log-prob of "5" is extremely low -> per their plausibility regression, belief
  implantation will be weakest and need the most data; probes likely to still flag it.
